# 循序 · 力扣官方判题扩展

此扩展连接公开学习网页与用户自己已登录的力扣中国站，在力扣官方运行 Hot 100 提交，回传 Accepted、Wrong Answer、时间 / 内存限制、运行错误等实际判题结果。包含原学习机器人的最近 AC 查询策略，支持按计划起始日期同步。

## 安装一次

1. 在 Chrome 或 Edge 中下载本项目 ZIP 并解压，或使用本机项目中的 `extension` 文件夹。
2. 打开 `chrome://extensions`（Edge 使用 `edge://extensions`）。
3. 开启右上角「开发者模式」，点击「加载已解压的扩展程序」，选择 `extension` 文件夹。不要选择仓库根目录。
4. 在同一浏览器登录 `https://leetcode.cn/`。
5. 打开或刷新 `https://taskii-lei.github.io/study-coach/`。题目作答区应显示「力扣扩展已连接」。

## 使用

- 在本站编辑器编写 `class Solution`，函数签名由题目模板给出。LRUCache / MinStack / Trie / MedianFinder 使用对应类模板。
- 点击「提交到力扣判题」或按 Ctrl / Cmd+Enter。**这会使用你的力扣账号创建一次真实提交。**
- 结果出现在本站「提交记录」，附官方提交链接及力扣实际返回的失败用例、预期与实际输出、耗时和内存；官方没有返回的字段不会编造。
- Accepted 会完成当前待办。你仍可自评理解程度来安排间隔复习。
- 在学习设置中填写力扣个人主页用户名和计划开始日期，可同步最近 AC。接口只返回近期通过记录；查不到不表示没通过或答案错误。
- 「停止等待」只停止扩展查询；已发送到力扣的提交会继续执行。遇到超时或网络中断，先查看官方记录，再决定是否重试。

## 权限与数据

`storage` 保存扩展拥有的力扣标签页编号和请求去重信息。`scripting` 只在 `https://leetcode.cn/` 标签页中执行提交和查询，浏览器自动携带该网站自己的会话。扩展不索取密码、不保存或上传登录 Cookie，不需要 API Key；不会把会话交给 GitHub Pages 或其他服务器。只允许固定的学习网页路径发起请求，题目受 100 道白名单限制。

请求使用力扣网页当前的接口，这些接口未承诺为稳定公共 API。若力扣改版、要求页面验证、退出登录或限制请求，扩展会显示错误并让用户在官网处理，不会代过验证，也不会把接口失败记作 Accepted。

代码题判题目前限 Hot 100。LLM 自编题和口述题由 Codex 教练批改，不会冒充力扣判题。

## 验证范围

仓库测试覆盖请求白名单、消息来源、提交 / 查询调用、AC / WA / 登录失效等分支、备份恢复与界面流程；测试使用隔离的模拟响应，不冒充真实账号判题。首次安装并登录后，需要用一题做真实端到端验证。
